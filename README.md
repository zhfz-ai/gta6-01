Solmara: Sunset Heist is a 3D open-world crime game built for the "Make GTA 6" bounty on make.fun. Dario Cole drives for Vera Solano across Solmara, a sun-soaked coastal city rendered in three.js (vendored under game/vendor/, no network requests at runtime). Five story missions, live traffic and pedestrians, a wanted level with police chases and roadblocks, fists and pistol combat, taxi fares, stunt jumps and sun postcards, a HUD with a circular minimap, a start screen, pause, game over, and a localStorage save.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser.
