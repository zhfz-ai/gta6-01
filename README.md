Solmara: Sunset Heist — a 3D open-world driving game set in Solmara, a sun-soaked coastal metropolis. Play Dario Cole, an ex-getaway driver paying off his late brother's debt to club owner Vera Solano across five story missions: steal cars, outrun the police, run courier drops, protect a courier van through a rival ambush, and finish with a 3-star sunset chase to the hills. Free-roam the city on foot or by car, with traffic, pedestrians, a 0–5 star wanted system with police chases and roadblocks, pistol combat, taxi fares, stunt jumps, and collectible sun postcards — plus a HUD with health, cash, wanted stars, mission objectives, speed, and a live minimap. Built with three.js, no network loads at runtime. Round 7 polish: brighter sunset lighting and roads, closer chase cameras, a legible pink mission beacon, and bigger, brighter police cars.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
