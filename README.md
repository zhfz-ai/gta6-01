Solmara: Sunset Heist — a 3D open-world action game that runs entirely in the browser. Drive and fight through the sun-soaked coastal city of Solmara as Dario Cole: steal cars, outrun the police across five wanted levels, run chained missions against club owner Vera Solano, and pull the sunset heist. Built with three.js, no network requests at runtime.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD to move/drive, E to enter/exit a car, Space for handbrake, mouse to aim, click to shoot.
